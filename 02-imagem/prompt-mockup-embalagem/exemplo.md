# Prompt de Mockup de Embalagem — exemplos reais

## Exemplo A — Você tem a arte final (aplicar como decal)
Entrada:
```
Estrutura: pote de vidro âmbar 200g, tampa preta
Artwork: tenho o PDF/PNG do rótulo (logo "Verde Raiz" + composição + registro)
Material/acabamento: vidro âmbar, rótulo fosco
Objetivo: fiel à produção (packshot do anúncio)
```
Saída:
```
Modo: aplicar artwork (fiel)

Use an image-editing / mockup AI that accepts the attached label artwork. Apply the provided
label ARTWORK AS-IS onto a 200g amber glass jar with a black lid — wrap it on the curved
surface with correct perspective, do NOT redraw, rewrite or restyle any text, logo, colors or
the registration/ingredient text; keep every printed element exactly as in the artwork file.
Amber glass material with a matte label finish, preserve the glass color and realistic
reflections. Single jar standing, front-facing so the label reads clearly, soft studio
lighting, subtle shadow, clean neutral background. Photorealistic mockup. Square 1:1.
Apply provided artwork as-is, do not rewrite label text, no invented claims, no fake barcode,
no watermark.
```
Modo: aplicar artwork · Ângulo: frontal (para ler o rótulo).
Observação: a cor na tela (RGB) é aproximada — não é a cor de impressão. Para a gráfica, use a
prova e os valores reais.

## Exemplo B — Sem a arte (conceito com placeholder seguro)
Entrada:
```
Estrutura: caixa de papel kraft para chá, ~10x6x6cm
Material/acabamento: kraft fosco
Artwork: ainda não tenho, só o nome "Verde Raiz"
Objetivo: conceito (ver o formato)
```
Saída:
```
Modo: conceito — rótulo em placeholder

Concept packaging mockup of a small matte kraft cardboard box (~10x6x6cm) for tea. Show the
brand name "Verde Raiz" as a simple clean wordmark on the front, and keep all other panels as
neutral placeholder areas with NO text — do not generate ingredients, weight, a nutrition table,
registration numbers or any pseudo-text. Kraft paper material with a matte finish, visible
paperboard texture, hero 3/4 angle to show the structure, soft studio light, subtle shadow,
neutral background. Photorealistic concept mockup. 1:1.
No invented claims, no fake nutrition facts, no fake barcode, no watermark.
```
Modo: conceito · 3/4 (para ver a estrutura, já que o objetivo é o formato).
Atenção: é um CONCEITO do formato — os textos obrigatórios (composição, peso, registro) e a
arte final entram depois, com os dados reais. A IA deixou tudo isso em branco de propósito.

## Exemplo C — Comparar acabamentos (mesma arte)
Entrada:
```
Já tenho o mockup do pote com a arte aplicada. Quero comparar rótulo fosco x com detalhe em
foil dourado só no logo.
```
Saída:
```
Modo: comparar acabamento (mesma arte, mesma estrutura)

A) Matte finish: [o mesmo mockup do pote, rótulo com acabamento totalmente fosco]

B) Foil accent:
Same jar and same applied artwork, unchanged. Keep everything identical EXCEPT the finish of
the logo area: render the "Verde Raiz" logo with a gold foil finish (reflective metallic
highlight that shifts with the light) while the rest of the label stays matte. Do not move or
redraw the artwork; only change the finish on the logo area. Soft studio light to reveal the
foil reflection.
```
Atenção: o foil dourado só no logo é um acabamento que precisa de área definida na arte — no
mockup é uma prévia; confirme com a gráfica se o foil naquela posição é viável antes de produzir.

> Referência: a arte real é aplicada, não redesenhada; o que não existe fica em branco (nunca
> tabela/registro/selo inventado); ângulo pelo objetivo (frontal para ler, 3/4 para estrutura);
> e a skill avisa que mockup não é prova de impressão nem "print-ready".
