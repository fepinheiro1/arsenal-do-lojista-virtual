# 02 · Imagem & Criativo

Cada skill aqui é um **gerador de prompt**: você preenche seus dados em português e recebe um **prompt de imagem em inglês**, pronto para colar numa IA de imagem (Midjourney, DALL·E, Nano Banana/Gemini, etc.). O inglês é de propósito — é onde os modelos de imagem entregam melhor. Todos orientam a incluir sujeito, ângulo, luz, fundo, estilo e proporção.

| Skill | O que faz |
|-------|-----------|
| [`prompt-foto-packshot`](prompt-foto-packshot/) | Prompt de foto de produto em fundo limpo, padrão e-commerce (still de estúdio) |
| [`prompt-foto-lifestyle`](prompt-foto-lifestyle/) | Prompt do produto em contexto real de uso, com ambiente, clima e luz natural |
| [`prompt-cena-de-uso`](prompt-cena-de-uso/) | Prompt com uma pessoa usando o produto, focando o benefício em ação |
| [`prompt-banner-campanha`](prompt-banner-campanha/) | Prompt de banner/hero com espaço negativo para o texto entrar depois |
| [`prompt-troca-de-fundo`](prompt-troca-de-fundo/) | Prompt de edição para remover ou trocar o fundo de uma foto que você já tem |
| [`prompt-mockup-embalagem`](prompt-mockup-embalagem/) | Prompt de mockup realista da embalagem ou rótulo do produto |
