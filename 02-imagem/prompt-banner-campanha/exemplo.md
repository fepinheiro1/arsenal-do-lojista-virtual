# Prompt de Banner de Campanha — exemplos reais

## Exemplo A — Compor packshot real + copy zone funcional
Entrada:
```
Conceito: coleção de inverno, aconchego
Produto: manta de tricô cinza (tenho foto real para recortar)
Oferta: [entra no editor]
Cores da marca: bege e marrom quente
Formato: hero 16:9; o texto vai à esquerda (será branco)
```
Saída:
```
Modo: compor com packshot real

Winter campaign hero background. Take the real gray knitted throw blanket from the attached
photo (keep its exact color, knit texture and shape — do not regenerate it) and place it
neatly folded over a beige armchair on the RIGHT third of the frame. On the LEFT 40% keep a
calm, darker, low-detail area with a soft warm-brown gradient so white text placed there
stays legible (predictable contrast, no busy pattern, no highlights behind the text). Warm
directional window light, cozy winter mood, brand palette of beige and warm brown.
Photorealistic, high detail. Wide 16:9 hero composition. No added text, no added letters,
no added logo, no watermark, no color change.
```
Modo: compor com foto real · Formato: 16:9, resolução de hero desktop (não 8K).
Copy zone: 40% esquerdo, escuro e estável para texto branco.
Lembrete: "Coleção Inverno" e a oferta entram por cima no editor — o preço/% real é você quem preenche.

## Exemplo B — Mesma campanha, dois formatos (versões irmãs)
Entrada:
```
Mesma campanha de inverno, agora quero hero de site e capa de story.
```
Saída:
```
Desktop hero (16:9): [como no Exemplo A — produto à direita, copy zone escura à esquerda]

Story/Reels cover (9:16):
Vertical winter campaign background. The same folded gray knitted blanket (from the attached
photo, unchanged) resting on the beige armchair in the LOWER-CENTER, with a calm darker area
across the TOP third for text, and the very top and bottom kept clear of the Stories
interface (safe zones). Same warm beige/brown palette and window light. 9:16 composition.
No added text, no added logo, no watermark, no color change.
```
As duas são a mesma campanha (mesma paleta, luz e produto), com composição própria — o 9:16
não é um corte do 16:9: o produto desce para o centro-baixo e a copy zone vai para o topo,
longe da UI do story.

## Exemplo C — Data comercial sem claim falso
Entrada:
```
Conceito: Black Friday da loja de eletrônicos
Produto: fone de ouvido (tenho foto)
Oferta: descontos reais entram no editor
Formato: 1:1 feed
```
Saída:
```
Modo: compor com packshot real

Bold Black Friday campaign background for a feed post. Place the real headphones from the
attached photo (exact model and color) as the focal point, slightly off-center, against a
clean dark brand-colored backdrop with a subtle energetic light accent — NO explosions, NO
countdown, NO "sold out" shelves, NO crowd. Keep a calm high-contrast area for the offer text
to be added later. Modern, high-energy but honest mood. 1:1 composition. No added text, no
added letters, no added logo, no watermark, no color change.
```
Modo: compor com foto real · Formato: 1:1, resolução de feed.
Atenção: energia sim, urgência falsa não. "50% OFF", "última chance" e o cronômetro entram
(ou não) por cima como texto, com o desconto REAL — a arte não encena uma escassez que não existe.

> Referência: o texto e a oferta sempre por cima (a IA erra letra e não pode inventar
> número); a copy zone é uma área de contraste de verdade, não só "vazio"; cada formato ganha
> composição própria; e a arte não vira claim (sem explosão, escassez ou "eco" sem base).
