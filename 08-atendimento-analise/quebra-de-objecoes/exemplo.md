# Quebra de Objeções — exemplos ilustrativos

> Casos de demonstração: só o confirmado vira afirmação; contas conferidas por código.

## Exemplo A — Preço com comparação (categoria regulada)
Entrada:
```
Canal: WhatsApp
Mensagem: "Gostei, mas achei caro. No concorrente tá mais barato."
Produto: kit sérum de vitamina C (30 ml) + hidratante (50 ml)
Confirmado na ficha: sérum com 10% de vitamina C; frasco com bomba dosadora. O lojista acha que
  a concentração é "maior que a do concorrente", mas não sabe a do outro.
Oferta: R$ 219 · frete grátis acima de R$ 199 · sem desconto autorizado
Suporte real: a equipe ajuda a montar a rotina de uso pelo WhatsApp
Tom: próxima, especialista, sem ser vendedora
```
Saída:
```
Diagnóstico: objeção de preço, com comparação (o cliente disse). Hipótese: ele está comparando
o preço, não necessariamente a mesma coisa. Nenhuma pressão; vale comparar pelos mesmos critérios.

Resposta (WhatsApp):
Faz todo sentido comparar! Para ficar justo, vale olhar os mesmos pontos nos dois: quantidade
(o nosso kit tem sérum de 30 ml e hidratante de 50 ml), a concentração de vitamina C (o nosso tem
10%) e o frete — o nosso kit já entra no frete grátis, que vale acima de R$ 199. Se ajudar, a
gente monta a sua rotina de uso por aqui. E se o outro fizer mais sentido para você, tudo bem também.

Fora, de propósito:
- "Concentração maior que a do concorrente": sem o número do outro, não dá para comparar.
- "Não perde efeito, você aproveita o pote inteiro": o frasco ter bomba dosadora não comprova
  efeito, e cosmético pede cuidado redobrado.
- "Custo de não resolver o problema": seria pressão pelo medo.
Próximo passo: aguardar a comparação do cliente; sem follow-up insistente.
Pendência: nenhuma (tudo o que foi dito está na ficha e na oferta).
```

## Exemplo B — Compatibilidade, "vou pensar" e pedido de reserva
Entrada:
```
Canal: chat do site
Mensagem: "Gostei da capinha, mas vou pensar. Ela serve no iPhone 15? Consegue segurar uma pra
  mim até sexta?"
Confirmado na ficha: compatível com iPhone 15 Pro. No catálogo há o mesmo modelo para iPhone 15
  ("Capinha Linha Areia — iPhone 15", em estoque).
A loja não reserva produtos.
```
Saída:
```
Diagnóstico: três pedidos — compatibilidade, "vou pensar" e reserva. A compatibilidade decide tudo.

Resposta:
Pela ficha, esta capinha é indicada só para o iPhone 15 Pro — para o iPhone 15 eu não
recomendaria. Para o 15, temos o mesmo modelo nesta linha: a Capinha Linha Areia — iPhone 15.
Pensa com calma! Só não consigo separar uma para você: a loja não faz reserva, então
a disponibilidade é a que aparecer na página na hora da compra.

Por que assim:
- O cliente ouve que o produto que ele olhou não é o indicado — dizer isso é parte de ajudar a decidir.
- A alternativa é real (está no catálogo).
- "Vou pensar" respeitado: sem insistir, sem "últimas unidades".
- Nada de "guardo pra você" se a loja não reserva.
Pendência: nenhuma — o modelo indicado está no catálogo e em estoque.
```

## Exemplo C — Parece objeção, é reclamação
Entrada:
```
Mensagem: "Achei caro e, sinceramente, a última que comprei de vocês veio rachada."
```
Saída:
```
Diagnóstico: há uma reclamação (produto anterior com defeito) junto da objeção de preço. A
reclamação vem primeiro e não é momento de vender.
Resposta: Que chato receber a peça rachada, desculpa por isso. Me passa o número daquele pedido
(aqui no privado) que eu já vejo a troca para você.
Encaminhar para respostas-de-atendimento (troca/garantia). A objeção de preço fica para depois,
se o cliente quiser.
```

> Referência: o que o cliente disse fica separado da hipótese; a resposta só usa informação
> confirmada e compara pelos mesmos critérios; nenhum atributo vira promessa de efeito; não há
> medo, urgência nem reserva inventada; o cliente ouve quando o produto não serve; e reclamação é
> resolvida antes de qualquer argumento de venda.
