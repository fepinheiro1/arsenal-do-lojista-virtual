# FAQ do Produto — exemplos ilustrativos

> Casos de demonstração: cada resposta vem da entrada — o que não dá para provar vira pendência.

## Exemplo A — Criar (produto simples, sem inventar)
Entrada:
```
Produto: Camiseta básica de algodão, gola redonda, masculina
Specs: 100% algodão, cores preto/branco/cinza, tamanhos P–GG
```
Como a skill age: entrega poucas FAQs fortes (produto simples), só com o que foi dado. O que não dá para provar não vira resposta com "[preencher]" no meio — vira pendência no fim.

Saída:
```
**Quais tamanhos tem?**
Do P ao GG.

**De que material é feita?**
100% algodão. Disponível em preto, branco e cinza.

Antes de publicar, confirme (aí eu incluo estas respostas):
- Qual tamanho escolher? → preciso das medidas de cada tamanho (corpo ou peça).
  Se a página já tem tabela de medidas, me diga e eu aponto para ela; se não tem,
  dá para montar com a skill tabela-de-medidas.
- Encolhe na lavagem? → orientação de lavagem do fornecedor.
- A cor desbota com o tempo? → confirmar com o fornecedor.
```

## Exemplo B — Minerar atendimento (perguntas reais → clusters)
Entrada:
```
Essas são as perguntas que chegam no meu WhatsApp sobre a air fryer:
- Ana: "cabe um frango inteiro?"
- Ana: "e um frango médio, entra?"
- Carlos: "é 110 ou 220?"
- Bia: "qual a voltagem dela?"
- Bia: "precisa untar?"
```
Como a skill age: agrupa as duas de frango num cluster e as duas de voltagem em outro. Conta menções, não clientes — as duas de frango vieram da mesma pessoa —, e os nomes não saem do histórico: nada de dado pessoal na entrega. Como não recebeu specs oficiais, entrega em modo preparação sem inventar.

Saída:
```
Perguntas reais identificadas (juntei as equivalentes; nomes ficam fora):
- Cabe um frango inteiro? (2 menções, da mesma pessoa)
- É 110V ou 220V? (2 menções, de 2 pessoas)
- Precisa untar? (1 menção)

Nenhuma dá para responder sem os dados oficiais. Me confirme e eu devolvo a FAQ pronta:
- Capacidade (litros) e o tamanho máximo que cabe → ficha técnica.
- Voltagem: 110, 220 ou bivolt → rótulo/manual.
- Precisa untar? → instrução do fabricante.
```

## Exemplo C — Suplemento sem rótulo (o caso crítico, corrigido)
Entrada:
```
Produto: Whey concentrado 900 g sabor baunilha.
(Nenhum rótulo, tabela nutricional ou instrução fornecidos.)
```
Como a skill age: descobre as perguntas certas, mas NÃO inventa dose, número de porções, preparo, horário nem lactose/glúten — nada disso está no que foi dado. Categoria sensível: tudo vira pendência.

Saída:
```
As dúvidas que mais pesam na compra deste produto são as de baixo — mas nenhuma
pode ser respondida sem o rótulo, então vão como pendência (não invento resposta):

Antes de publicar, confirme (com o rótulo/fabricante):
- Contém lactose? → alergênicos do rótulo.
- Contém glúten? → alergênicos do rótulo.
- Qual a porção indicada? → tabela nutricional.
- Quantas porções rende os 900 g? → tabela nutricional.
- Como preparar? → instrução do fabricante.

Me mande o rótulo (ou uma foto dele) e eu transformo cada uma numa resposta confirmada.
```

## Exemplo D — Otimizar (tira propaganda e resposta vaga)
Entrada:
```
Melhore esta FAQ:
P: Por que esse fone é o melhor da categoria?
R: Porque ele tem a melhor qualidade e o melhor som do mercado.

P: Tem bluetooth?
R: Sim, tecnologia sem fio de última geração.
```
Como a skill age: remove a pergunta promocional (é copy, não FAQ) e troca a resposta vaga por uma factual — ou pendência, quando o dado não veio. "Tem Bluetooth" é declaração do próprio lojista sobre o produto dele, então continua como resposta; "de última geração" ninguém comprovou, então sai. Versão e alcance, que ninguém declarou, viram pendência.

Saída:
```
Removida: "Por que esse fone é o melhor da categoria?" — é propaganda, não tira
dúvida de compra.

**Conecta por Bluetooth?**
Sim, é sem fio por Bluetooth.

Antes de publicar, confirme (aí eu detalho):
- versão do Bluetooth e alcance;
- se acompanha cabo ou estojo de carga (conteúdo da caixa).
```

> Referência: pergunta na voz do cliente, resposta só quando há fonte, o que falta
> vira pendência clara — nunca invenção. Não afirma o que existe na página sem saber;
> conta menções, não clientes; dado pessoal nunca sai. Categorias sensíveis
> (suplemento) exigem rótulo.
