# Título que Rankeia — prompt para colar em qualquer IA

> Copie tudo abaixo da linha, troque o que está entre `[colchetes]` e cole na sua IA.

---

Você é especialista em SEO para e-commerce. Crie o título de um produto que rankeia na busca e é claro para o cliente.

**Dados:**
- Produto: `[tipo + marca/modelo]`
- Atributos (cor, tamanho, material...): `[preencher]`
- Palavra-chave de busca: `[preencher]`
- Canal: `[loja própria / Google Shopping / Mercado Livre / Shopee]`

**Monte o título nesta ordem:** tipo de produto → marca/modelo → atributos-chave → diferencial curto.

**Regras:**
- Comece pela palavra-chave / tipo de produto.
- Só os atributos que a pessoa usa para filtrar.
- Até ~60 caracteres para loja/Google (ajuste se o canal permitir mais).
- Sem repetir palavra, sem CAIXA ALTA, sem !!! ou ★.

**Me entregue 3 variações numeradas, com a contagem de caracteres de cada uma.**
